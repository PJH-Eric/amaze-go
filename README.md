# 箭頭解密（Amaze GO）

點箭頭讓它沿尖端方向飛出棋盤；被別的箭頭擋住就撞回。可愛粉彩風，手機／平板／桌機皆可玩。

## 啟動
- `npm install`，再 `npm start`（或雙擊 `啟動遊戲.bat`）→ http://localhost:3080（同一個 port 同時提供網頁與 WebSocket）
- `npm test`：規則測試（有解保證、緊密排列、1,000 關、隨機開局）
- `node scripts/check-random.js`：單機隨機模式五難度、勝敗、原盤重玩／新盤、闖關紀錄隔離與中英文 8 種尺寸 RWD（需 Playwright／Chromium；`RANDOM_SCREENSHOTS` 可指定截圖目錄）。
- `node scripts/check-initial-zoom.js`：8 種尺寸逐一初始化全部 1,000 關，另驗證兩種對戰模式的五難度隨機盤面、手動縮放、旋轉與重玩（需 Playwright／Chromium；`ZOOM_SCREENSHOTS` 可指定截圖目錄）。
- `node scripts/check-expansion.js`：驗證五種難度的舊成績、100→101／199→200 關、解鎖、末關重玩，以及 12 種尺寸（含斷點兩側）的 200 關選單與統計。每排在 760px 以上為 10 關、400～759px 為 5 關、399px 以下為 4 關，觸控按鈕至少 48px（需 Playwright 與 Chromium）。
- `npm run verify`：規則測試 + 線上整合測試（真 WebSocket：房間、邀請、觀戰、搶飛、電腦、重連、零真人關房）
- `node scripts/check-replay.js`：闖關重玩、末關、失敗重試、鍵盤焦點與 8 種視窗尺寸巡檢（需環境提供 Playwright 與 Chromium；截圖預設存於系統暫存目錄，可用 `REPLAY_SCREENSHOTS` 指定）。
- `node scripts/check-countdown.js`：對電腦／線上模式的 8 種尺寸倒數回歸與中英文等待房間房名／工具列防重疊，涵蓋下一盤、開始提示、背景布局穩定與倒數期間禁止操作（需 Playwright 與 Chromium；可用 `COUNTDOWN_SCREENSHOTS` 指定截圖目錄）。
- `node scripts/check-levels.js`：5 組獨立玩家、日期、尺寸與 CPU 速度設定，逐一比對全部 1,000 關的 SHA-256 與實際開局（需 Playwright 與 Chromium；可用 `LEVEL_SCREENSHOTS` 指定截圖目錄）。

## 模式
- **單機隨機模式**：首頁選擇「單機隨機模式」，自由選擇五種難度後產生可解的隨機盤面，不使用關卡、解鎖或五星評價。愛心與提示沿用所選難度；結算顯示耗時、目標時間／達標狀態、失誤與提示，目標時間沿用闖關的難度與箭頭數量計算。「重來／重玩這盤」還原原盤與資源，「再來一局（新盤面）」產生新盤，結算提供新盤、重玩這盤、重選難度與回首頁四個動作；遊戲中返回可重新選擇難度。支援離線、中英文及既有全盤優先 RWD；不修改闖關進度、星數、最佳時間及闖關難度偏好。GA4 遊玩事件以 `solo_random` 區分。
- **耗時顯示**：闖關、對電腦與線上對戰統一使用 `分:秒.百分秒`（例如 `1:23.45`）；最佳紀錄、結算與目標時間也顯示兩位小數，成績仍以毫秒保存。
- **棋盤空間與觸控**：所有模式共用「全盤優先」的初始化視圖：完整顯示時每格至少約 10px，就維持全盤、不自動產生捲軸；更密集的盤面才適度放大至每格約 14px（最多 3.5 倍），保留自訂捲動。自動視圖會隨旋轉／側欄空間重新評估；手動縮放後保留玩家選擇，鍵盤 `0` 可查看全盤，新局／重玩重新初始化。闖關按鈕保留至少 44px；桌機棋盤區最大寬度 1,200px，手機橫向使用窄版側欄。
- **對戰頂列**：對電腦／線上模式將計時與延遲徽章整合進精簡頂列，取消獨立計時列；等待房間隱藏對局計時與比分，窄螢幕將房名獨立換行，手機直向將比分換行、計時與延遲上下排列並預留高度，橫向沿用左側資訊欄。離開與縮放按鈕保留至少 44px，進度條縮至 6px，讓棋盤取得更多空間。
- **固定闖關盤面**：`public/js/levels-v1.js` 保留各難度第 1～100 關的原始 500 關；`public/js/levels-v1-extra.js` 追加第 101～200 關的 500 關，合計 1,000 關，皆屬於 `story-v1`。擴充關卡延續各難度後期尺寸，逐步增加最多 2 格。同一難度與關卡的遮罩、箭頭位置、方向及順序固定，僅顯示比例依裝置調整；開局不使用時間、亂數、排序或即時輪廓運算。每次開局複製資料，玩家操作不會修改其他玩家的盤面。`tests/fixtures/levels-v1.sha256.json` 與 `levels-v1-extra.sha256.json` 分別鎖定原始與新增關卡的逐關雜湊；不得重新生成或覆寫既有版本，新增關卡版本須另建資料檔。更新前已開啟的舊版頁面須重新載入，才會使用固定盤面。
- **過關重玩**：結算可選「下一關」或「重玩這關」；重玩還原開局棋盤並重設計時、愛心、失誤及提示，保留最佳成績。最後一關提供「重玩這關」，失敗則提供「再試一次」。窄版與橫向視窗沿用自繪捲軸，所有操作皆可到達。
- **闖關模式**：五種難度（幼幼班～神話）各 200 關，共 1,000 關、最高 5,000 星（各難度最高 1,000 星）（盤型為 46 種實物／幾何輪廓，非方形），依序解鎖，第 100 關通過後接續第 101 關，第 200 關結算提供重玩；既有進度、星數與最佳時間保留。每關 1～5 星（過關 1 星；失誤 0 次 +2、≤難度門檻 +1；提示用量在難度允許內 +1；耗時在目標內 +1，失誤／提示門檻與目標時間皆依難度而異）。
- **對戰模式（對電腦）**：每個房間最多 3 位玩家（1 位真人＋最多 2 位電腦），各電腦可獨立選難度；可選 1～5 盤，累計總分高者勝（同分比最後一盤，仍同分並列）。在瀏覽器內執行與線上相同的規則，不需連線。
- **對戰模式（線上）**：同上，另有房間、邀請連結、觀戰、聊天；真人與電腦可同房，房主直接在空位點難度加入電腦、或在電腦座位換難度／移除。
- **動畫**：箭頭點擊後沿著自己的路徑滑出（頭領先、身體隨轉彎跟進）；滑鼠移上去會浮起；箭頭尖端畫在最上層，不會被其他線條蓋住。
- **上一頁**：瀏覽器／手機的返回鍵會依畫面回到上一層；首頁左上角有「← 遊戲小小島」按鈕，首頁按上一頁也會回遊戲大廳（網址在 `public/js/config.js` 的 `lobbyUrl`）。
- **線上對戰**：大廳＋公開房間、快速加入、2～4 席（真人＋電腦合計）、觀戰、邀請連結（玩家／觀戰，房主可撤銷重發，6 小時過期）、電腦五段難度（反應速度與失誤率不同，困難、神話會挑長箭頭）、聊天室（自由輸入＋快捷短語）。
- **搶飛規則**：同一棋盤誰先點中就得分（箭頭越長分越高），點到被擋住的扣 1 分（最低 0），清空棋盤後分數高者勝；每局隨機盤型。
- **房間生命週期**：以「真人玩家」為準，真人玩家降為 0（電腦與觀戰者不算）立即關閉房間，邀請失效並通知房內成員，已關閉的房號不能復活。
- **自繪元件**：按鈕、開關、捲軸（內容超出時顯示粉彩自繪捲軸，可拖曳／點軌道）、輸入框外觀皆為自訂樣式，不使用瀏覽器原生外觀。
- **版面**：資訊欄（計分）＋聊天室合為一個小側欄，可縮合；寬版在左側，窄版（手機／平板直向）為左下角小彈層，頂部另有縮小的計分晶片；棋盤盡量放大。

## 設定與部署（預設：GitHub Pages 前端 + Render 後端）
- `public/js/config.js` 是唯一的 server URL 入口；Pages workflow 在建置時用 repo variable `GAME_SERVER_URL`（Render 後端的 HTTPS URL）取代。同源部署（`npm start`）時留空即可。
- Render：`render.yaml` 已指定 `region: singapore`；請在 Render 設定 `GAME_ALLOWED_ORIGIN`（前端 origin）。健康檢查 `/health`。
- 注意：Render 免費方案會休眠，房間只存在記憶體（重啟即消失）；Blueprint 設定不等於實際服務區域，已建立的服務不能改 region，需要新加坡節點請另建服務。
- `.env.example` 列出環境變數；不要把秘密放進前端。
